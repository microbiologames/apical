Ambiance

Six endroits où le jeu se tient, pas six humeurs. En bas, dans le temps de la vésicule, il n'y a pas de batterie : une mesure n'a aucun sens quand une exocytose dure 0,85 s. Elle monte avec l'échelle, comme le reste.

Ce que le jeu envoie

Quatre grandeurs, et le moteur n'en connaît pas d'autres. Ce sont celles que la simulation sait déjà produire.

à l'arrêt

Ce qui sort

 

Chaque pic est comparé à la médiane de son propre tiers d'octave. Une raie n'est pas un défaut : une nappe tenue seule en donne une à ×24, une cloche à ×82 — c'est la définition d'une note. Ce qui se signale ici, c'est une raie immobile pendant seize secondes, alors que l'harmonie a changé deux fois : celle-là n'est pas une note, c'est un filtre ou une réverbe qui chante.

Le code

—

 

Le code porte l'ambiance, les seize réglages généraux, les six racks et la graine. C'est tout ce qu'il faut pour que le morceau soit le même chez celui qui le charge.
